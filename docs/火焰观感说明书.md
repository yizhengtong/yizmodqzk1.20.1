> 这份文档写给**不画图、不写着色器**的人。

## 0. 三十秒版

**游戏里的火，其实是四件事拼出来的：**

| 你以为你在看 | 其实你在看 |
|---|---|
| 火的**形状** | 一团"噪声"（花纹）被一个**阈值**切出来的舌状物 |
| 火的**颜色** | 一条**三段色带**（暗红 → 橙黄 → 白热），按"离火心多近 + 离地多高"取色 |
| 火的**体积** | 从体表往外**走几步、每步累加一点光**（不是贴一张图） |
| 火的**活** | 噪声**往上流**（上升）、按时间**抖**（闪烁）、**出生→长大→熄灭**（生灭） |

**你只需要回答三个问题**（详见第 4 节）：

1. **火舌粗细**：像蜡烛那样一小簇一小簇（细），还是像柴堆那样一大团一大团（粗）？
2. **颜色温度**：橙红（柴火）／ 黄白（煤气灶、喷射）／ 蓝青（酒精灯、魔法火）？
3. **火有多实**：能透出身体材质（薄、好看）还是几乎挡住身体（厚、凶）？

**在游戏里直接看现成的 6 种**（不用改代码、不用重启）：

```
/yiz flame preset list          ← 列出全部 6 种（带一句话描述）
/yiz flame preset classic       ← 默认档「经典/Classic」（旧名 candle 仍可用）
/yiz flame preset blue          ← 切成"蓝焰/魔法火"
/yiz flame burning follow       ← 给最近的实体挂"贴模型着火"（爬满全身那条路径）
/yiz flame burning              ← 给自己挂"贴模型着火"（第一人称会自动挂体积火兜底）
/yiz flame off                  ← 全部熄掉
```

> 预设**只换观感**（粗细／快慢／浓淡／明暗／颜色／火舌长度／火星多少），
> **不换"火焰多高"** —— "不超过身高一半"是你定过的硬规矩，写死在着色器里，任何预设都越不过去。

## 1. 火焰在画面上是由什么拼出来的

### 1.1 形状：火的"轮廓"是噪声切出来的

真实火焰没有固定形状 —— 它是**热气在乱流里翻滚**。所以所有 3D 火焰都用一个"噪声场"来假装乱流：

```
   噪声场（一团有粗有细的花纹）        阈值一刀切下去          你看到的火舌
   ░░▒▒▓▓▒░░▒▓▓▒▒░░                 阈值 0.62              ░░  ▓▓   ░   ▓▓
   ░▓▓▓▓▓▒░░▒▓▓▓▒░      ────►       只保留 >0.62 的部分  ────►     ▓▓▓     ▓▓▓
   ░░▒▓▓▒░░░░▒▓▒░░                   （其余全透明）              ▓▓       ▓
```

三个旋钮，每个对应一种"看起来像什么"：

| 旋钮 | 往大调看起来像 | 往小调看起来像 |
|---|---|---|
| **噪声频率**（花纹的"密"） | 火舌**细、条数多**：蜡烛、煤气灶、喷射口 | 火舌**粗、成一团团**：柴堆、营火、闷烧 |
| **阈值**（切多狠） | 空隙大、**一簇簇、斑驳**、能看到身体从缝里透出来 | 糊成一片、**像套了一层壳**（"很丑"最常见的原因） |
| **上升流速** | 火**窜得快、抖得急**（着急、凶） | 火**慢慢舔**（沉稳、将熄） |

> 打比方：噪声频率 = 面条的粗细；阈值 = 面条之间的汤有多少；上升流速 = 锅底火多大、汤滚得多快。

### 1.2 层次：外焰→中层→核心，是"温度"画出来的

现实火焰的颜色来自**温度**（炽热物体发光，越热越白）：

```
   温度/颜色对照（简版"黑体辐射"）

   400℃        800℃         1100℃        1400℃+
   暗红    →    橙红    →    橙黄    →    黄白/白热
   ████        ████         ████         ████
   最外侧       外焰          中层          核心（火心）

   本模组用的三段色（默认档）：
     核心 CORE = (1.00, 0.95, 0.75)  ← 白热微黄
     中层 MID  = (1.00, 0.55, 0.12)  ← 橙黄
     外焰 EDGE = (0.55, 0.09, 0.02)  ← 暗红
```

**还有一条"下热上冷"的规律**：火根最热（贴着火源）、火苗尖端最冷（已经在散开了）。
所以同一个火里，"白热"只出现在**火舌根部、且位于火舌最中心**的地方；越往上、越靠边，颜色越退回橙红。

> 这两条如果搞反（比如整团火都算成白热），观感会变成"越烧越白、像镁条" —— 不像火。

### 1.3 体积感：为什么"往外积分一段"比"贴一层壳"像火

火焰不是固体表面，它是**半透明的发光气体**。所以正确做法是"**沿着视线一步一步往里面走，每走一步就加一点光、同时被遮掉一点**"：

```
   贴一层壳（错的做法）              往外积分（本模组的做法）
   ┌──────────────┐                ┌──────────────┐
   │  一张橙色皮   │                │ ·  ·  ·  ·   │ ← 每走一步：加光、减透过率
   │  贴在模型上   │                │ · ·  ·  ·    │    6~16 步，共约 0.42 格（贴模型火）
   └──────────────┘                │·  ·  ·       │
   边缘是"刀切"的硬边                └──────────────┘
   转动视角没有厚度变化               边缘自然渐隐，转视角有"厚度"变化
```

专业名词叫**射线步进（ray marching）+ 参与介质（participating media）+ 预乘 alpha**，翻成人话：

- **射线步进**：从你的眼睛出发，穿过火焰，一路采几个点；
- **参与介质**：每个点不是"有/没有"，而是"有多浓" —— 浓的地方加光多、也挡得多；
- **预乘 alpha**：最后输出的颜色**已经乘过透明度**（`颜色 × 透明度`），
  这样"发光"和"遮挡"能分开算 —— 这正是"提亮 ≠ 变实"的技术基础（见 1.6）。

### 1.4 动态：火为什么会"活"

| 动态 | 做法 | 看起来像 | 本模组的旋钮 |
|---|---|---|---|
| **上升** | 采噪声时把纵坐标随时间往下拉 | 花纹往上跑 = 火焰向上窜 | `flow` / `FLOW` |
| **抖动/闪烁** | 噪声随时间变化 + 采样起点抖动 | 火苗边缘不停抖、忽明忽暗 | `flow`、`iTime`（时间）、`uSteps` 的抖动 |
| **生灭** | 每团火有"出生→长大→淡出"三段 | 火苗一个个冒出来、长大、熄掉（不是一直同样大） | `fadeIn` / `fadeOut`、`GROW_TICKS`、`MIN/MAX_RADIUS` |
| **火星** | 偶尔生成一朵"更小更亮更短命"的火 | 从火里溅出来的橙点，一闪而过 | `sparkChance`、`SPARK_RADIUS/HEIGHT/LIFE` |
| **随风/朝向** | 噪声锚点跟着实体走，或固定在世界上 | 人转身火跟着转（贴模型火）；或火留在原地 | `Anchor.ENTITY/WORLD`、`followYaw` |

### 1.5 颜色：黑体辐射简版 + 为什么有"蓝火"

- **柴火/蜡烛（橙黄系）**：燃烧产物里有炽热的碳粒，碳粒发光 → 走"暗红→橙→黄→白"这条温度色带。
- **蓝焰（酒精灯、煤气灶、本模组的"蓝焰/魔法火"预设）**：燃烧充分、几乎没有碳粒，
  发光靠的是**分子本身**（比如 CH、C₂ 自由基），颜色偏蓝青 —— 而且**蓝色部分其实更热**，
  只是亮度低、白天几乎看不见。
- **"地狱火/魔法火"**：现实里不存在的颜色（青绿、紫、纯黑），做法就是**直接换三段色**，
  不遵守黑体辐射 —— 反正是魔法。

### 1.6 透明度与发光：为什么"暗贴图上的火会显脏"，以及**正确做法是提亮而不是加不透明**

这一条正是上一轮"特效变丑、几乎看不见"的核心，值得单独讲：

```
   输出是"预乘 alpha"：屏幕结果 = 火的颜色 + 被火挡掉一部分的背景

   情况 A：火亮（颜色 > 0）           情况 B：火被算成"黑"（颜色 = 0）
   ┌──────────────┐                  ┌──────────────┐
   │ 亮橙 + 身体   │                  │ 黑 × 半透明  │
   │ = 身体上挂着  │                  │ = 身体被压暗  │
   │   一层光 ✓    │                  │   一层脏影 ✗  │
   └──────────────┘                  └──────────────┘
```

**为什么在深色贴图的生物身上火会显"深/脏"**：火焰本身半透明，模型底色会从火里透出来。
亮皮肤（玩家）透出来还是亮的 → 好看；暗贴图（僵尸、凋灵骷髅、监守者）透出来发黑 → 火"变脏"。

**两种应对方式，差别很大**：

| 做法 | 结果 |
|---|---|
| ✗ **提高不透明度**（把火变实、挡住底色） | 火变成一层壳，看不见身体材质 —— 用户明确说过"透明的才好看" |
| ✓ **提高亮度**（火自己的颜色乘一个 >1 的数） | 火更亮、更"发光"，但仍能透出身体 —— **只提亮、不变实** |

本模组把这两件事**分成两个旋钮**：
`brightness`（乘在颜色上，管"多亮"）和 `opacity`（乘在 alpha 上，管"能透出多少"）。
上一轮的教训是把两者一起往上推、并且把火线压得太低 → 观感崩了（见 2.4 的真凶）。

### 1.7 常见风格速查（关键词 → 视觉特征）

| 风格 | 关键词 | 视觉特征 |
|---|---|---|
| **经典（classic，旧名 candle）** | 小、柔、抖、白黄 | 一小簇，细碎火舌，几乎贴着物体，能透出材质，抖得慢 |
| **火把** | 细长、上窜、亮核心 | 窄而高，火舌条数多，核心亮黄，边缘橙红，风吹会歪 |
| **营火** | 宽、慢、橙红、火星多 | 一大团横向铺开，火舌粗，颜色偏橙红，火星不断往上飘 |
| **火焰喷射器** | 强湍流、拉长、黄白 | 顺着一个方向拉得很长，内部翻腾剧烈，亮黄白发白，声音感"猛" |
| **地狱火（蓝）** | 青蓝、冷、稀薄 | 蓝白偏青，边缘深蓝，看起来"冷"但实际更热，白天几乎看不见 |
| **魔法火（青绿/紫）** | 不真实、纯净、发光 | 违反黑体辐射，颜色干净、渐变硬，像"能量"而不是"燃烧" |
| **余烬** | 低矮、暗红、慢闪 | 火很低很暗，一明一灭节奏慢，主体是暗红 + 零星亮点 |

### 2.2 旋钮 → 观感对照表（★ = 预设里能直接调的）

| 旋钮 | ★ | 往**大**调 | 往**小**调 |
|---|---|---|---|
| `noiseScale` 噪声尺度 | ★ | 火舌**更细更碎、条数更多** → 煤气灶 | 火舌**粗、成团** → 柴堆 |
| `flow` 上升流速 | ★ | 窜得**快**、闪烁急 → 凶、猛 | 慢慢舔 → 沉稳、将熄 |
| `density` 密度 | ★ | **浓、实**、容易糊成壳 | 稀、透亮、虚 |
| `turbulence` 湍流阈值 | ★ | **空隙大、斑驳、一簇簇**（能看到身体） | 糊满一片、像壳 |
| `opacity` 透明度上限 | ★ | 更**挡住**本体颜色 | 更**透**，材质看得清 |
| `brightness` 亮度 | ★ | 火**自己更亮**（不变实）→ 暗贴图生物不再发脏 | 火发暗、发灰 |
| `marchLength` 光程 | ★ | 火舌从体表**往外舔得更远、更蓬松** | 贴着表面薄薄一层 |
| `falloffK` 向外衰减 | ★ | 火舌**短而虚** | 拖尾**长**、像被风吹出去 |
| `edgeFadeMin` 轮廓最低强度 | ★ | 轮廓那圈也亮 → 整体更"整块" | 外沿**渐隐** → 更薄更飘 |
| `core/mid/edge` 三段色 | ★ | —— | —— （换的是色相：橙→蓝→青绿→紫） |
| `sparkChance` 火星概率 | ★ | 火星**多**（营火、爆燃） | 火星少、干净 |
| `SPREAD_LINE_MAX` 火线高度 | | **火更高**（⚠ 越"身高一半"这条线） | 火更低（⚠ 低于 0.42 会整体显淡） |
| `SPREAD_NOISE` 火线锯齿 | | 边缘**更参差**（像一簇簇爬上去） | 边缘更平（像水位线） |
| `SPREAD_SOFT` 渐隐带宽 | | **外沿更柔和、晕开**（"透明好看"的来源） | 边缘更硬、范围更小 |
| `MAX_TOP_RATIO` 最高点比例 | | 体积火团能更高 | 更低（⚠ 压太狠 = 只在脚边冒火星） |
| `PATCH_HEIGHT` 单团高度 | | 每团火更大更高 | 更小（⚠ 太小 + 第一人称 = 几乎看不见） |
| `uSteps` 步数 | | 更细腻（**更吃帧**） | 更糊、更省 |
| `uOctaves` 湍流层数 | | 细节更多（**更吃帧**） | 更简单、更省 |

### 2.3 本模组有**两条**渲染路径（同一把火，视角不同走不同路）

| 路径 | 什么时候用 | 画面长什么样 | 参数来源 |
|---|---|---|---|
| **贴模型火** `rendertype_flame_surface` | 第三人称、看别的实体 | 火**顺着模型（头/躯干/四肢）舔出来**，从下往上爬 | `FlameStylePreset`（逐帧读 uniform） |
| **体积补丁火** `rendertype_flame_volume`（`Shape.BURNING`） | 第一人称自己着火（原版不画自己的模型）、以及"火星" | 一圈**小团火**绕在身体上，从下往上冒 | 生成时读同一份预设 |

两条路径**共用同一套观感来源**（这就是"玩家/生物观感一致"的代码级保证）——
所以你切一次预设，两条路径一起变。

### 2.4 一个必须知道的坑：**GLSL 里用了、但 `.json` 里没声明的 uniform → 整片火变黑**

上一轮"特效很丑、几乎看不见"的真凶就是它，不是那些观感常数：

```
Java 侧                                   GLSL 侧
safeGetUniform("uBrightness")              uniform float uBrightness;
      │                                        │
      ├─ 在 .json 的 "uniforms" 里？             │ 没人上传 → 保持默认值 0
      │     否 → 返回"空实现"（DUMMY），set() 什么也不做
      ▼                                        ▼
 你以为设置了 1.35                       fragColor.rgb = 颜色 × 0 = 全黑
                                            │
                       预乘混合：黑颜色 + 非零 alpha = 把本体压暗的一层脏影 ✗
```

**两个修复（都已落地）**：

1. 在 `rendertype_flame_surface.json` / `rendertype_flame_volume.json` 的 `"uniforms"` 里
   **声明 `uBrightness`，默认值 1.0**；
2. 着色器里加**防呆**：`float bright = uBrightness > 0.0 ? uBrightness : 1.0;`
   —— 以后就算有人替换资源包把这个声明弄丢，火也只是"不提亮"，而不会变成黑块。

> 记住这条规律：**往着色器里加一个 uniform，必须同时在 `.json` 里声明它**，否则它的值永远是 0。

## 4. 怎么告诉我"你要哪种火"

你**不需要**说参数名。下面这些话我都能直接翻译：

| 你说 | 我改什么 |
|---|---|
| "我要第 3 种 / 营火的" | 切到预设 `campfire`（或把它设成默认档） |
| "比现在更蓝一点" | 预设 `blue` 的三段色往青蓝推，或从 `classic` 直接换成 `blue`（旧名 `candle` 亦可） |
| "火舌更细一点，条数多一点" | `noiseScale` ↑（4.4 → 6~8） |
| "火窜得更快 / 更急" | `flow` ↑（2.2 → 4~6） |
| "太实了，我想更透、能看见身体" | `opacity` ↓（0.85 → 0.7~0.75） |
| "太淡了，几乎看不见" | `brightness` ↑（1.0 → 1.2），必要时 `density` 轻微 ↑；**不要**靠加不透明度 |
| "像套了层橙色壳，很丑" | `turbulence` ↑（0.62 → 0.7）、`density` ↓ |
| "火舌太短，像贴纸" | `marchLength` ↑、`falloffK` ↓ |
| "边缘太硬、一刀切" | `SPREAD_SOFT` ↑、`edgeFadeMin` ↓ |
| "火星多一点 / 少一点" | `sparkChance` ↑ / ↓ |
| "火再大一点，但**别超过半身**" | `PATCH_HEIGHT` ↑（体积侧）；贴模型火的高度上限**不动** |
| "颜色偏黄白 / 偏橙红 / 偏暗" | 调三段色 `core/mid/edge`，或换预设 |

### 常见"丑" → 处方

| 症状 | 大概原因 | 处方 |
|---|---|---|
| 整片火发黑、像一层脏影 | uniform 没在 `.json` 声明（值=0） | 已修 + 着色器防呆；以后新增 uniform 必须声明 |
| 几乎看不见 | 火线压太低 / 体积火团太小 / 亮度被算成 0 | `SPREAD_LINE_MAX` 回 0.45；`PATCH_HEIGHT` 回 0.55；检查 `uBrightness` |
| 糊满、像壳 | `turbulence` 太低、`density` 太高 | ↑湍流、↓密度 |
| 发灰、不发光 | 亮度不足 + 底色暗 | ↑`brightness`（不是 ↑`opacity`） |
| 火太高、烧到胸口 | 火线比例超了 | 调 `SPREAD_LINE_MAX`，但**别低于 0.42**（再低就整体显淡） |
| 边缘硬切 | 渐隐带太窄 | ↑`SPREAD_SOFT`、↓`edgeFadeMin` |
| 一顿一顿 / 卡 | 步数或层数太高 | ↓`uSteps` / ↓`uOctaves`（见 2.2） |

## 5. 附录

### 5.1 高度约束是怎么算的（"不超过身高一半"）

```
贴模型火（着色器）：
   火线 = mix(0.00, 0.45, uSpread)            ← uSpread 由 Java 从 0 推到 1
   实际前沿 = 归一化高度 + 列噪声(±0.06)
   遮罩 = 1 - smoothstep(火线, 火线 + 0.34, 实际前沿)
   ⇒ 满强度最高点 ≈ 0.45 + 0.06 = 0.51 身高（≈ 一半 ✓）
   ⇒ 再往上只剩渐隐尾巴（很淡，0.85 身高处归于无）

身高基准 = 目标自己的 getBbHeight()（不写死 1.8）⇒ 2.9 格的监守者也按"自己的一半"

体积补丁火（Java，`FlameEffects.BurningSpread` = 旧版"碰撞箱补丁"路径）：
   单团火高度 = MIN_HEIGHT 0.32 → MAX_HEIGHT 0.75 格（每 tick 长 0.0126，34 tick 长满）
   补丁中心   = 0.04 ~ 0.48 × 身高（MIN_CENTER_RATIO 0.04 / DEFAULT_MAX_CENTER_RATIO 0.48）
   ⇒ 玩家（1.8 格）补丁中心最高 0.864 格，火苗大致到 1.6 格（腰以上）

   注意：这条路径**不**吃"不超过身高一半"那条硬规矩 —— 那是**贴模型火**的约束；
        体积补丁是旧版兜底（第一人称自己着火时自动挂上），刻意允许烧到腰以上。
```

### 5.4 一句话总结

> **火 = 噪声切出来的形状 + 一条温度色带 + 沿视线积分出来的厚度 + 会流动会闪烁会生灭的动态。**
> 你觉得"丑"，八成是这四样里某一样被调过头（最常见：切太狠变壳、压太矮变淡、亮度算成 0 变黑）。
> 你不用描述参数，**指一个编号或者说一句"更蓝/更细/更透/更猛"就够了。**
